# Quickstart: GraphCore Data Layer

## Prerequisites

- Unity 2022.3 LTS or later
- `com.faolline.graphcore` package added to your project

---

## 1. Create a BaseGraph asset

In the Unity Editor, right-click in the Project window:

```
Create → GraphCore → Base Graph
```

The asset's `GraphId` is assigned automatically on creation. Every graph gets a unique,
stable GUID that survives renames and moves.

---

## 2. Inspect the graph in the Inspector

A freshly created `BaseGraph` shows:

| Field | Default | Description |
|-------|---------|-------------|
| Graph Id | `<auto-generated>` | Read-only GUID |
| Entry Node Id | `""` | Set after adding a StartNode |
| History Depth | `20` | Set to `0` for unlimited |
| Nodes | `(empty)` | Populated by the graph editor |
| Edges | `(empty)` | Populated by the graph editor |
| Parameters | `(empty)` | Add typed variables here |

---

## 3. Add parameters

Add a `ParameterData` entry to the graph's Parameters list:

| Parameter | Type | Default Value |
|-----------|------|---------------|
| `IsQuestComplete` | `Bool` | `"false"` |
| `PlayerLevel` | `Int` | `"1"` |
| `Reputation` | `Float` | `"0.5"` |
| `PlayerName` | `String` | `"Hero"` |

Default values are stored as strings. The runtime layer reads and converts them.

---

## 4. Work with node data in code (editor tooling or tests)

```csharp
// Create a StartNode
var start = new StartNodeData
{
    Id = System.Guid.NewGuid().ToString("D"),
    NodeType = StartNodeData.NodeTypeId,   // "graphcore/start"
    Position = Vector2.zero
};

// Create a ChoiceNode with two choices
var choice = new ChoiceNodeData
{
    Id = System.Guid.NewGuid().ToString("D"),
    NodeType = ChoiceNodeData.NodeTypeId,  // "graphcore/choice"
    Position = new Vector2(200, 0),
    Choices = new List<BaseChoice>
    {
        new BaseChoice { Id = System.Guid.NewGuid().ToString("D") },
        new BaseChoice { Id = System.Guid.NewGuid().ToString("D") }
    }
};

// Add to graph (via editor API — not direct list manipulation at runtime)
graph.Nodes.Add(start);   // through editor tooling
graph.EntryNodeId = start.Id;
```

## 5. Extend with a custom node type (downstream lib)

```csharp
// In your lib's Runtime assembly
[System.Serializable]
public class DialogueLineNodeData : StatementNodeData
{
    public const string NodeTypeId = "dialoguesystem/line";

    [SerializeField] private string _speakerKey;
    [SerializeField] private string _textKey;

    public string SpeakerKey => _speakerKey;
    public string TextKey    => _textKey;
}
```

No graphcore file needs modification. The `[SerializeReference]` on `BaseGraph.Nodes`
handles the new subtype automatically.

## 6. Extend BaseCondition and BaseAction

```csharp
// A condition that checks a graph parameter
[CreateAssetMenu(menuName = "GraphCore/Conditions/Has Parameter")]
public class HasParameterCondition : BaseCondition
{
    [SerializeField] private string _key;
    [SerializeField] private string _expectedValue;

    public override bool Evaluate(BaseContext context)
    {
        // Resolved at runtime using context — implementation in runtime layer
        return false;
    }
}
```

## 7. Validate a graph asset in an EditMode test

```csharp
[Test]
public void BaseGraph_GraphId_IsAssignedOnEnable()
{
    var graph = ScriptableObject.CreateInstance<BaseGraph>();
    graph.SendMessage("OnEnable");  // or: graph.hideFlags = HideFlags.HideAndDontSave;
    Assert.IsFalse(string.IsNullOrEmpty(graph.GraphId));
    Object.DestroyImmediate(graph);
}
```
